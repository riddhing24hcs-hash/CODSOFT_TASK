# Contact Book Application

## About the Project

The Contact Book is a Python GUI application developed using Tkinter and SQLite. It helps users manage their contacts easily.

## Features

- Add new contacts
- View saved contacts
- Search contacts by name or phone number
- Update existing contacts
- Delete contacts
- Store contact details using SQLite database

## Technologies Used

- Python
- Tkinter
- SQLite3

## How to Run

1. Install Python on your computer.
2. Download or clone this project.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
py main.py
```
